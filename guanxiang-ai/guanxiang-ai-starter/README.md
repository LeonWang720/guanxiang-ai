# 观相 AI · 中国传统面相学知识库

**English:** Guanxiang AI · Chinese Physiognomy Knowledge Base

A bilingual digital knowledge base studying traditional Chinese physiognomy through classical texts, historical research, and careful cultural analysis.

## Project principles

- Treat physiognomy as a historical and cultural subject.
- Cite editions, volumes, chapters, and page numbers wherever possible.
- Distinguish primary texts, later interpretations, modern scholarship, and editorial notes.
- Mark uncertain claims as `待考证` / `Unverified`.
- Do not present facial appearance as a scientifically valid basis for inferring character, morality, health, wealth, or destiny.

## Local development

```bash
npm install
npm run docs:dev
```

Build the site:

```bash
npm run docs:build
npm run docs:preview
```
